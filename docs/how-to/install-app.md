# Install TeamSync and use it offline

This guide shows you how to install TeamSync so it opens like an app, and how to use it without internet.

## Install on Android, Chrome or Edge

1. Open [TeamSync](https://simeontsvetanov.github.io/teamsync-random-team-generator/) in Chrome or Edge.
2. Go to **Menu** > **Install app**.
3. Confirm the install in your browser's prompt.

On a computer, you can also use the install icon in the address bar. When TeamSync is installed, the menu item reads **Installed ✓**.

## Install on iPhone or iPad

1. Open TeamSync in Safari.
2. Select **Share** (the square with an arrow).
3. Select **Add to Home Screen**.
4. Keep **Open as Web App** turned on.
5. Select **Add**.

TeamSync appears on your Home Screen and opens in its own window.

## Use TeamSync offline

Open TeamSync once while you're online. After that first visit, it works without internet, whether you installed it or not. When you're offline, TeamSync shows **Offline — still works**.

Everything TeamSync does runs on your device, so creating, shuffling and copying teams all work offline. Sharing to WhatsApp or another app needs internet only to send the message.

When a later version is available, TeamSync shows **New version available**. Select **Reload** to use it.
