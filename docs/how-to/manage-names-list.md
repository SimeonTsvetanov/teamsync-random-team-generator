# Keep or clear your names list

TeamSync remembers your last names list and number of teams on this device. This guide shows you how to reuse the list or remove it.

## Reuse your last list

Open TeamSync on the same device and in the same browser. Your last list and number of teams are already filled in, so you can select **Generate teams** right away. To change the list, edit the names in **Names**.

## Clear the names list

1. Next to **Names**, select **Clear**.
2. Optional: To get the list back, select **Undo** in the message that appears.

The **Names** box is empty.

## Clear the names and the teams

1. Under the teams, select **Clear and start over**.
2. In **Clear the names and teams?**, select **Clear**.

The list and the teams are removed from this device, and you start with an empty list.

## Delete all your data

To remove everything TeamSync saved on this device, including your theme and language, go to **Menu** > **Settings** and select **Clear my data**. Then, in **Delete all your data?**, select **Delete**. This can't be undone.
