# TeamSync

**Create fair, random teams in seconds** · [Open the app](https://simeontsvetanov.github.io/teamsync-random-team-generator/)

> **For AI agents:** docs at [llms.txt](https://simeontsvetanov.github.io/teamsync-random-team-generator/llms.txt) ·
> local MCP: `npx -y @simeonts/teamsync-random-team-generator-mcp`

Split any list of names into fair, random teams in seconds. Free, private and works offline — everything runs in your browser.
